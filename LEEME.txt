ADJUNTAR EL FOLLETO EN PDF A LOS MAILS DE CAMPAÑA
════════════════════════════════════════════════════

HAY 3 PASOS. LOS 3 SON NECESARIOS, EN ESTE ORDEN:

PASO 1 — Subir el PDF a Supabase (una sola vez, para siempre):
1. Andá a supabase.com → tu proyecto (construía)
2. Menú izquierdo → Storage
3. Create a new bucket
   - Nombre: adjuntos (exacto, minúscula)
   - Marcá la opción "Public bucket" (importante: tiene que ser
     público, si no, Resend no va a poder leerlo)
   - Create bucket
4. Entrá al bucket "adjuntos" → Upload file
5. Subí el archivo nexo-folleto.pdf (el mismo que ya tenés) — pero
   ANTES de subirlo, fijate que se llame exactamente
   "nexo-folleto.pdf", sin números ni espacios. Si tu archivo
   descargado tiene otro nombre, renombralo primero en Archivos.

PASO 2 — Actualizar la función que manda los mails:
1. Supabase → Edge Functions → enviar-mail
2. Pestaña "Code" (o el ícono de editar)
3. Borrá todo el código actual y pegá el contenido completo del
   archivo enviar-mail.ts que te mando acá
4. Deploy / Publicar

PASO 3 — Subir el index.html (como siempre):
Solo index.html. Confirmá el nombre exacto antes de subir.
"Add file → Upload files", nunca el lápiz.

QUÉ CAMBIA EN LA APP:
En Comercial → ✉ Campaña → Modo autónomo, ahora hay un checkbox
"Adjuntar el folleto de NEXO en PDF", tildado por defecto. Cada
mail que mandes desde ahí (autónomo o con revisión) va a llevar el
folleto adjunto, salvo que destildes esa casilla.

SI EL NOMBRE DEL ARCHIVO EN STORAGE ES DISTINTO:
La app espera encontrarlo exactamente en esta dirección:
https://agcmhrbxqtibrtmhwrrx.supabase.co/storage/v1/object/public/adjuntos/nexo-folleto.pdf
Si subiste el bucket o el archivo con otro nombre, avisame y te
doy la línea corregida para volver a subir.
